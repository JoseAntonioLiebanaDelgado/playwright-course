# 🎭 Playwright Automation Course

QA Automation learning project focused on building practical testing skills with **Playwright**, starting with JavaScript and progressively moving toward more advanced automation concepts and framework design.

This repository will evolve throughout the course as new concepts, tests and automation practices are implemented.

## 🚀 Tech Stack

* Playwright
* JavaScript
* TypeScript
* Node.js
* Git & GitHub
* GitHub Actions
* API Testing

## 🎯 Project Goals

The main goal of this repository is to develop solid QA Automation skills and understand how a professional Playwright automation project is built.

The project will progressively cover:

* Playwright fundamentals
* JavaScript fundamentals applied to automation
* Browser, Context and Page management
* Locators and element interaction
* Assertions and validations
* Forms and user interactions
* Handling dropdowns, checkboxes and radio buttons
* Waiting strategies
* Frames and iframes
* Popups and multiple tabs
* Screenshots, videos and traces
* Test hooks
* Fixtures
* Test data management
* Page Object Model (POM)
* Reusable components and utilities
* API testing with Playwright
* Authentication and session management
* Data-driven testing
* Parallel execution
* Cross-browser testing
* Test reports
* Debugging and error analysis
* Git and GitHub workflow
* Continuous Integration with GitHub Actions
* JavaScript to TypeScript progression
* Automation framework structure and best practices

## 📚 Learning Approach

The repository contains practical exercises and tests developed while progressing through the course.

The objective is not only to learn Playwright commands, but also to understand how to design, organize and maintain automated tests in a real QA Automation project.

## 🏁 Final Objective

By the end of the project, the goal is to have a complete Playwright automation framework covering UI and API testing, reusable architecture, test data management, reporting and CI/CD integration.

The project will initially use **JavaScript** and progressively incorporate **TypeScript** as the automation framework becomes more advanced.
